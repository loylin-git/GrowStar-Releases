## 功能

### 记录
- **支持多个孩子**：姓名、性别、出生日期、父母身高、头像照片（可拖动缩放取景，自动压缩到长边 512 px）。
- **身高体重记录**：精确到秒的记录时间，一天一条自动合并；BMI 自动计算。
- 电脑端为可排序表格，手机端为卡片列表。

### 图表
- **身高 / 体重 / BMI 三种曲线**，原生绘制（不依赖第三方图表库），支持按钮缩放与双指缩放。
- 叠加 **CDC 2000 / WHO 2007** 的 **P3 / P15 / P50 / P85 / P97** 参考百分位线，图表内一键切换标准。
- 从最近一次实测延伸出的**预测曲线**（虚线）与当天日期竖线。
- 右上角可把**成长图分享**给微信等系统社交应用。

### 预测
- 未满 4 岁或尚无实测：使用**中亲身高法（Tanner 公式）**。
- 4 岁及以上且有实测身高：**Khamis-Roche 法**与**当前百分位位置**按年龄加权混合，起点锚定真实测量值，随年龄增长逐步收敛。
- 成年终点统一取 **19 岁**。

### 数据与设置
- **导入导出**支持 **JSON（默认）**、CSV、XLSX、SQLite，可覆盖用户表（头像以 base64 内嵌）、成长数据表与应用设置表。CSV 自动识别 UTF-8 / UTF-8 BOM / GBK(GB18030) 编码，Excel 另存的文件不会乱码。
- **单位切换**：厘米 ↔ 英寸、千克 ↔ 磅；数据库始终以公制存储，仅在显示与录入处换算。
- **三语界面**：简体中文 / 繁體中文 / English，切换即时生效。
- **主题配色**按孩子分别设置，页面底色、卡片与文字色由主题色自动派生。
- 内置**免责声明**与**隐私政策**；设置页可**分享应用**给他人；**退出应用需确认**，避免误触丢失数据。

## 隐私

- 应用**不含任何联网代码**：没有 HTTP 客户端、没有广告、没有统计与崩溃上报，连 `INTERNET` 权限都没有声明。
- 所有数据保存在本机 SQLite 数据库与应用数据目录下的头像文件夹。
- 唯一权限是导入导出与选择头像时的文件读取（Android 12 及以下）。
- **删除用户、清除应用数据或卸载会永久删除数据**，请定期用导出功能自行备份。

## 预测方法说明

参考数据以 **LMS 参数**（L 偏度、M 中位数、S 变异系数）内置：

- **CDC Growth Charts (2000)**：年龄别身长/身高、体重、BMI
- **WHO Child Growth Standards / Growth Reference (2007)**：年龄别身高、体重、BMI

百分位由 LMS 配合 probit（逆正态）变换计算。成年身高预测：

1. `P`：Khamis-Roche 预测的成年身高在 19 岁曲线上的百分位；
2. `Q`：最近一次实测身高在当前年龄曲线上的百分位；
3. `w = (年龄 − 4) / 15`，限幅到 0~1：`R = w·P + (1 − w)·Q`；
4. 最终成年身高 = 19 岁曲线上第 `R` 百分位对应的身高。

未来曲线沿 `R` 百分位线做时间折算绘制，因此起点严格等于最近实测身高、终点严格等于预测的成年身高。

## 常见问题

**预测的身高准吗？**
它是基于人群统计的估算，与实际成年身高可能存在数厘米甚至更大的偏差，会随新录入的数据变化，不是临床结论。完整局限说明见应用内「免责声明」。

**换手机怎么迁移数据？**
旧设备「导出 → JSON」，把文件传到新设备后「导入 → JSON」。JSON 单文件包含用户、头像、记录与设置。

**CDC 和 WHO 选哪个？**
WHO 2007 是「应该长成什么样」的**标准**（多国多民族样本）；CDC 2000 是「美国样本实际长成什么样」的**参考**。日常对照两者皆可，建议选定后保持一致。

**会同步到云端吗？**
不会。没有服务器，也没有同步功能。导出文件是数据离开设备的唯一途径，且由你选择保存位置。
